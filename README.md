# Yash Sisodia — AI & Machine Learning Portfolio

A modern, interactive portfolio web application showcasing projects in Machine Learning, Computer Vision, AI RAG Pipelines, and Data Analytics.

## 📁 Project Structure

```
portfolio/
├── assets/
│   ├── profile.jpg
│   └── Yash-Sisodia-CV.pdf
├── css/
│   ├── animations.css
│   ├── base.css
│   └── components.css
├── js/
│   ├── background.js
│   ├── components.js
│   ├── data.js
│   └── main.js
├── index.html
└── README.md
```

## 🛠️ Tech Stack & Features

- **HTML5 & Vanilla CSS**: Modular CSS design system splitting reset/base styles, UI components, and animations.
- **JavaScript (ES6+)**: Structured into modular data management, UI component rendering, and application logic.
- **Three.js**: Interactive 3D particle network background animation reacting to cursor movement.
- **AOS (Animate On Scroll)**: Smooth entrance animations for section cards and timeline items.
- **Responsive Layout**: Designed for mobile, tablet, and desktop viewports.

## 🚀 Quick Start

Simply open `index.html` in your web browser or serve it using any HTTP server:

```bash
# Option 1: Using Python
python3 -m http.server 8000

# Option 2: Using Node / npx
npx serve .
```
